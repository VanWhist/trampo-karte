# 短期目標フォーム設問案（月次振り返り・任意で後日作成）

MIC選手育成の「フォームA/B」（月次で振り返り→新しい目標を回答してもらう仕組み）を参考にした、
瑛斗・颯斗向けの簡易版の設問案。今回はGoogleフォーム自体はまだ作成していません。作る場合は
以下の質問をそのままGoogleフォームにし、回答先スプレッドシートを `apps-script/Code.gs` が
参照する「短期目標」タブに指定してください（列名の対応は下記の通り）。

## 設問

1. 名前（ラジオボタン: 瑛斗 / 颯斗）
2. 前回からの振り返り（自由記述、任意）
   - 「前回立てた目標に対してどうだったか、できたこと・難しかったことを教えてください」
3. 新しい目標（自由記述）
   - 「次の期間で達成したい目標を教えてください」
4. 挑戦したい技（自由記述、任意）
   - 「今度チャレンジしてみたい技があれば教えてください」

## スプレッドシート列名との対応

Googleフォームの「回答」→スプレッドシートを作成すると、質問文がそのまま列見出しになります。
`apps-script/Code.gs` は「短期目標」タブの以下の列名を前提にしているので、フォーム作成後に
列見出しをこの名前にリネームしてください（または `Code.gs` 側の列名を実際のフォームの質問文に
合わせて書き換えても構いません）。

| Code.gsが期待する列名 | 対応するフォーム設問 |
|---|---|
| タイムスタンプ | （フォームが自動生成するタイムスタンプ列） |
| 名前 | 1. 名前 |
| 振り返り | 2. 前回からの振り返り |
| 新しい目標 | 3. 新しい目標 |
| 挑戦したい技 | 4. 挑戦したい技 |

毎月同じフォームを使い回す想定なので、文言に「今月」「来月」等の特定の月を入れず、
「前回」「次の期間」のような汎用表現にしてあります（MICのフォームBと同じ工夫）。
