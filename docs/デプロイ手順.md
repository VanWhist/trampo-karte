# デプロイ手順

このアプリを実際に動かすには、(1) Googleスプレッドシート+Apps Scriptのバックエンドと、
(2) GitHub Pagesでのフロントエンド公開、の2つが必要です。MIC選手育成の選手カルテと同じ方式
（ログイン不要・トークン付きURL）ですが、今回はバックエンドを1つのスプレッドシート＋1つの
Apps Scriptにまとめてあるので、デプロイの手間はMICよりかなり少ないです。

## 1. Googleスプレッドシートを作成する

1. Google Driveで新規スプレッドシートを作成し、名前を「瑛斗颯斗選手カルテ_DB」などにする。
2. 下記6つのタブ（シート）を作成し、1行目に指定のヘッダーをそのまま入力する。

### タブ「名簿」

| token | 名前 | 有効 |
|---|---|---|
| e8e183033ebb85ca4dfaf8b8 | 瑛斗 | TRUE |
| ada5cb88c3ea6391860c3813 | 颯斗 | TRUE |

※ トークンは今回`trampo-karte`用にランダム生成した値です。他の人に推測されないよう、
このシート自体は共有しないでください（Apps Script経由でのみ参照されます）。

### タブ「シーズン目標」

| 名前 | 目標 | 期限 | 更新日 |
|---|---|---|---|
| 瑛斗 | （ここに目標を入力） | | |
| 颯斗 | （ここに目標を入力） | | |

Vanさんが直接このシートを編集して更新する運用です（フォームは無し）。

### タブ「マンダラ」

| 名前 | データJSON | 更新日 |
|---|---|---|
| 瑛斗 | | |
| 颯斗 | | |

「データJSON」列には下記のような形式のJSON文字列をそのまま入力します（1セルに1行で書けます）。

```json
{"center":"中心目標（例: 全日本ジュニア入賞）","subGoals":[
  {"title":"技術","actions":["","","","","","","",""]},
  {"title":"フィジカル","actions":["","","","","","","",""]},
  {"title":"メンタル","actions":["","","","","","","",""]},
  {"title":"生活習慣","actions":["","","","","","","",""]},
  {"title":"","actions":["","","","","","","",""]},
  {"title":"","actions":["","","","","","","",""]},
  {"title":"","actions":["","","","","","","",""]},
  {"title":"","actions":["","","","","","","",""]}
]}
```

8つのサブ目標と、各サブ目標につき8つのアクション項目を埋めていく形（マンダラチャート/曼荼羅シート）。
最初は空欄のままで問題なく、後から少しずつ埋めていけます。

### タブ「短期目標」

| タイムスタンプ | 名前 | 振り返り | 新しい目標 | 挑戦したい技 |
|---|---|---|---|---|

最初は見出し行だけでOK。将来Googleフォームを作る場合は、このシートをフォームの回答先に
指定し、質問文をこのヘッダーに合わせてください（`docs/短期目標フォーム設問案.md` 参照）。
それまでの間はVanさんが手入力しても構いません。

### タブ「技記録ログ」

| id | タイムスタンプ | 名前 | 技 | 本数 | 成功数 | メモ | 動画URL |
|---|---|---|---|---|---|---|---|

見出し行だけでOK。アプリの「＋ 記録を追加」から書き込まれます。

### タブ「コーチメモ」

| id | タイムスタンプ | 名前 | 発信者 | 本文 |
|---|---|---|---|---|

見出し行だけでOK。アプリの共有メモ欄から書き込まれます。

## 2. Apps Scriptを設定する

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く。
2. デフォルトで開かれる `Code.gs` の中身を全て削除し、このリポジトリの `apps-script/Code.gs`
   の内容をそのまま貼り付けて保存する。
3. 右上の「デプロイ」→「新しいデプロイ」をクリック。
4. 種類の選択で歯車アイコン→「ウェブアプリ」を選択。
5. 「実行ユーザー」= 自分（Vanさんのアカウント）、「アクセスできるユーザー」= 全員、に設定。
6. 「デプロイ」をクリックし、初回は権限の確認画面が出るので許可する
   （自分のGoogleアカウントで自分のスクリプトを承認するだけなので安全です）。
7. 発行された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec` の形式）を
   コピーしておく。

## 3. フロントエンドにURLを設定する

`karte/index.html` を開き、以下の行を書き換える。

```js
var API_URL = "PUT_YOUR_APPS_SCRIPT_EXEC_URL_HERE";
```

↓

```js
var API_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

## 4. GitHubに公開する

1. GitHub（VanWhistアカウント）に新規Publicリポジトリ「trampo-karte」を作成する
   （リポジトリ名はASCII文字にする。日本語名だとURLが不安定になるため）。
2. このフォルダの中身（`index.html` `karte/` `eito/` `soto/` `apps-script/` `docs/`）を
   まるごとアップロードする（GitHubのWeb画面の「Add file」→「Upload files」でドラッグ＆ドロップ
   するのが簡単。あるいは `git push` でも可）。
3. リポジトリの Settings → Pages で「Deploy from a branch」→ `main` / `root` を選択して公開する。
4. 数分後、以下のURLが動くようになる。
   - 保護者/コーチ用（2人を切り替えて閲覧）: `https://vanwhist.github.io/trampo-karte/`
   - 瑛斗専用: `https://vanwhist.github.io/trampo-karte/eito/`
   - 颯斗専用: `https://vanwhist.github.io/trampo-karte/soto/`

## 5. 動作確認

- 「名簿」タブの2行がそのままだと、いきなり本番トークンなので、必要ならこの場で
  新しいランダムなトークンに差し替えても構いません（`eito/index.html` `soto/index.html` の
  リンク先も同じ値に書き換えること）。
- シーズン目標・マンダラを1件だけ試しに入力し、`/eito/` からアクセスして反映されるか確認する。
- 技・ジャンプ記録ログで「＋ 記録を追加」→保存→再読み込みで表示されるか確認する。
- 共有メモを送信→保護者用画面と本人用画面の両方で表示されるか確認する。
