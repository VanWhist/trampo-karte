# 瑛斗・颯斗 選手カルテ（trampo-karte）

MIC選手育成で運用している「選手カルテ」（GitHub Pages + Google Sheets/Apps Script）の仕組みを、
瑛斗・颯斗の2名（トランポリン）向けに簡略化して作成したもの。

## 構成

- `karte/index.html` … カルテ本体。1つのファイルで「本人専用モード」（URLに `?token=` が付いている）と
  「保護者/コーチ用モード」（トークン無し＝両名を切り替えて閲覧）の両方を兼ねる。
- `eito/index.html` … 瑛斗専用URL（`karte/?token=...` へ自動リダイレクト）
- `soto/index.html` … 颯斗専用URL（同上）
- `index.html` … ルートアクセス時に `karte/` へリダイレクト
- `apps-script/Code.gs` … バックエンド（Google Apps Script、単一のWebアプリでシーズン目標・
  マンダラ・短期目標・技記録ログ・コーチへ共有メモの5機能をまとめて処理する）
- `docs/デプロイ手順.md` … Google Sheets + Apps Script + GitHub Pages への実際のデプロイ手順
- `docs/短期目標フォーム設問案.md` … 月次振り返り用Googleフォームの設問案（作成は任意・後回し可）

## 機能（今回実装した範囲）

- 目標設定（シーズン目標＋マンダラチャート）
- 短期目標（月次振り返り、フォームは後付け可）
- 技・ジャンプ記録ログ（トランポリン技、10本/20本などの本数と成功数を記録）
- コーチへ共有メモ（本人⇄保護者のやり取り）

トレーニングログ（ウエイトトレーニング）やジャッジ分析など、MIC選手カルテにある他の機能は
今回のスコープ外（必要になれば別途追加可能）。

## 現在の状態

このリポジトリのコードは Cowork のクラウド作業環境で作成したものです。GitHubへの実際の
push・Google Sheets/Apps Scriptの実デプロイはまだ行っていません。`docs/デプロイ手順.md` の
手順に沿ってVanさん側で公開してください。
